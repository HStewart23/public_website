# hannahstewart.dev *(placeholder — update once domain is chosen)*

My personal website — a short bio, photo, and links out to LinkedIn, GitHub, and Intersticia.

Live at: https://YOUR-DOMAIN-HERE.com

## Stack

Single static HTML file, no build step, no dependencies. Fonts loaded from Google Fonts via CDN.

## Updating the site

1. Edit `index.html` directly (bio text is in the `<section class="bio">` block, links are in the `<nav>` block).
2. Commit and push to `main`.
3. GitHub Pages redeploys automatically — usually live within a minute or two.

To swap the photo, replace `photo.jpg` with a new image of the same filename (square crop works best).
